# 🌍 Real-Time Screen Translator | المترجم المباشر للشاشة

برنامج خفيف ومفتوح المصدر مبني بلغة بايثون (Python) يقوم بقراءة النصوص من جزء معين من الشاشة (مثل الفيديوهات، الكورسات التعليمية، أو الألعاب) في الوقت الفعلي، وترجمتها من الإنجليزية إلى العربية باستخدام `Google Translate`، مع عرض الترجمة في نافذة شفافة عائمة (Always on Top).

## ✨ المميزات (Features)
- 🚀 **ترجمة فورية:** يلتقط الشاشة ويترجم النص باستمرار وبسرعة.
- 🧠 **مقارنة ذكية للخوارزميات:** يستخدم `SequenceMatcher` لمنع إعادة ترجمة نفس النص إذا لم يتغير بشكل كبير، مما يوفر استهلاك الإنترنت ويتجنب الحظر من سيرفرات جوجل.
- 👻 **واجهة شفافة وتفاعلية:** نافذة أنيقة لا تعيق الرؤية وتبقى دائماً فوق جميع النوافذ الأخرى، مع أزرار للتشغيل والإيقاف.
- ⚙️ **معالجة الصور المتقدمة:** استخدام `OpenCV` لتحويل الصورة إلى التدرج الرمادي (Grayscale) وتطبيق الفلترة (Thresholding) قبل استخراج النص لزيادة دقة القراءة.

## 🛠️ المتطلبات الأساسية (Prerequisites)

لتشغيل هذا البرنامج بنجاح، تحتاج إلى أمرين أساسيين قبل البدء:

### 1. تثبيت لغة بايثون (Python)
إذا لم تكن بايثون مثبتة على جهازك:
- قم بتحميل الإصدار الأخير من الموقع الرسمي: [Python.org](https://www.python.org/downloads/)
- **مهم جداً:** أثناء التثبيت، تأكد من وضع علامة صح (✔️) على خيار **`Add Python to PATH`** في النافذة الأولى قبل الضغط على `Install Now`.

## 🚀 طريقة التثبيت والتشغيل (Installation & Usage)

بعد التأكد من المتطلبات السابقة، افتح موجه الأوامر (Terminal أو CMD) ونفذ الخطوات التالية:

1. **استنساخ المشروع (Clone the repository):**
   قم بتحميل ملفات المشروع إلى جهازك عبر هذا الأمر:
   ```bash
   git clone https://github.com/mohammadsalehmoryt-png/real-time-screen-translator.git
   ```

2. **الدخول إلى مجلد المشروع:**
   ```bash
   cd real-time-screen-translator
   ```

3. **تثبيت المكتبات المطلوبة:**
   سيقوم هذا الأمر بتحميل جميع الإضافات اللازمة للبرنامج (مثل OpenCV وغيرها) بضغطة واحدة:
   ```bash
   pip install -r requirements.txt
   ```

4. **تشغيل البرنامج:**
   أخيراً، قم بتشغيل المترجم:
   ```bash
   python app.py
   ```

## ⚙️ تخصيص البرنامج (Customization)
إحداثيات مربع الالتقاط (Region) مضبوطة حالياً على قيم افتراضية في الكود:

```python
REGION = {"top": 1000, "left": 450, "width": 920, "height": 150}
```
يمكنك فتح ملف `app.py` وتعديل هذه الأرقام (الارتفاع، العرض، المسافة من الأعلى، المسافة من اليسار) لتتناسب تماماً مع حجم شاشتك وموقع الفيديو الذي تريد ترجمته.
