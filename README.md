# المترجم المباشر للشاشة — دون إنترنت

يلتقط التطبيق النص الإنجليزي الظاهر في منطقة من الشاشة، يستخرجه محليًا باستخدام Tesseract OCR، ثم يترجمه إلى العربية بنموذج Argos يعمل عبر CTranslate2 وSentencePiece على الجهاز. يترجم النص المرئي فقط، ولا يلتقط الصوت أو الكلام.

## الإعداد الأول (يحتاج إنترنت)

يلزم اتصال بالإنترنت مرة واحدة لتثبيت مكتبات التشغيل وتنزيل نموذج الإنجليزية–العربية الرسمي، حجمه نحو 84 ميغابايت. بعد ذلك يعمل التطبيق دون إنترنت:

```powershell
cd H:\AI_Projects\Tesseract
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe .\setup_offline_model.py
```

يحفظ الإعداد النموذج المستخرج داخل `models\installed\en_ar` في المشروع. بعد ظهور رسالة اكتمال التثبيت، يمكنك فصل الإنترنت.

## التشغيل دون إنترنت

```powershell
cd H:\AI_Projects\Tesseract
.\venv\Scripts\python.exe .\app.py
```

اضغط **تشغيل الترجمة المحلية**. إذا نُقل المشروع إلى جهاز آخر أو أُنشئت بيئة Python جديدة، ثبّت الاعتماديات والنموذج على ذلك الجهاز أثناء توفر الإنترنت.

## المتطلبات

- Windows وPython 3.10 أو أحدث.
- محرك Tesseract OCR مثبت مع بيانات اللغة الإنجليزية (`eng`).
- مساحة تخزين للنموذج (نحو 92 ميغابايت بعد فك الضغط) ومكتبات التشغيل.

يكتشف التطبيق Tesseract تلقائيًا من `PATH` أو من المسارات الشائعة. إذا كان مثبتًا في مكان آخر، اضبط متغير البيئة قبل التشغيل:

```powershell
$env:TESSERACT_CMD = 'C:\Program Files\Tesseract-OCR\tesseract.exe'
.\venv\Scripts\python.exe .\app.py
```

## منطقة الالتقاط

المنطقة الافتراضية شريط قرب أسفل الشاشة الأساسية، محسوب كنسب من أبعادها. يمكن تعديل القيم في أعلى `app.py`:

```python
REGION = {"x": 0.05, "y": 0.78, "width": 0.90, "height": 0.18}
```

القيم نسب بين `0` و`1`: `x` و`y` موضع بداية المنطقة، و`width` و`height` أبعادها. تغيير `y` إلى `0.70` يرفع المنطقة إلى أعلى الشاشة.

## ملاحظات

- يتعرف OCR على الإنجليزية (`eng`) ثم يترجم من الإنجليزية إلى العربية.
- النص والصورة لا يغادران الجهاز أثناء التشغيل. اتصال الإنترنت مطلوب فقط لتثبيت الاعتماديات وتنزيل النموذج أول مرة.
- قد تختلف جودة نموذج الترجمة المحلي عن الخدمات السحابية، لكنه يعمل محليًا وبسرعة معقولة للنصوص القصيرة.
- تظهر أخطاء Tesseract أو ملفات النموذج في نافذة التطبيق.
